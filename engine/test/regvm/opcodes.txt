# Every opcode of engine/quickjs-opcode.h, in its order, and its path into
# the register loop: NAME PATH [# note]. rvops (rvops.c) checks it against
# the engine. PATH is reg (an op of its own), pass (the abstract stack of
# the pass), window (a window op, regvm-ops-window.h, or W_GEN of
# regvm-ops-gen.h), old (OLD, regvm-ops-old.h) or never. The pass takes
# every opcode of final code: none is refused.
#
# never: the temporary opcodes of the compiler are in the code of no
# function. resolve_variables turns each scope_*, enter_scope,
# leave_scope, set_class_name and *_opt_chain into final code or drops it
# and copies only label and line_num, which resolve_labels drops, and their
# numbers are those of the short opcodes in final code. OP_invalid is made
# by no compiler, and check_polls (poll_scan) refuses it, and any number
# past the last opcode, in code JS_ReadObject reads.
#
# A line "> SOURCE" under an opcode is a form of it that must convert: a
# script whose value is a function, which rvops calls once with the
# register loop on. The forms at the end are functions the pass once
# refused whole and that convert now, and the limits of the parser that
# stand where the pass refused: a line '!"ERROR" SOURCE' is a script that
# must throw an error whose text starts with ERROR, the parser's, while the
# function it makes compiles.
