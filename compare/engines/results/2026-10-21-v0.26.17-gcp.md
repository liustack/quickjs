|---|---|---|---|
| liustack-quickjs | `github.com/liustack/quickjs` | `v0.26.16 => ../../` | Scripts are compiled to bytecode with VM.Compile and run with EvalBytecode. Intl comes from package intl, registered only when a test asks for it. |

| goant-interp | `github.com/robomotionio/goant` | `v0.2.1` | JIT off: goant.New() without WithJIT, the library default. Scripts are compiled with Runtime.Compile and run with RunProgram. A Program belongs to the Runtime that compiled it, so cold start parses the source on every VM. |
| goant-jit | `github.com/robomotionio/goant` | `v0.2.1` | JIT on: goant.New(goant.WithJIT(true)), the opt-in baseline JIT. Scripts are compiled with Runtime.Compile and run with RunProgram. A Program belongs to the Runtime that compiled it, so cold start parses the source on every VM. |
| moejs | `github.com/Calcium-Ion/moejs` | `v0.1.0-alpha.9` | Scripts are compiled once with moejs.CompileScript and run with Runtime.RunScript. A Script runs on any runtime. Runtimes are made with Options.MutableIntrinsics: test262, the Intl polyfills and the tifa bundles write to the builtins, which are frozen and shared by default (a new runtime costs about 25 times as much this way, by its guide). Promise jobs run before RunScript and CallFunction return, so RunJobs has nothing to do. Options.MemoryLimit counts what a runtime allocates between resets, not what is live. The call depth is fixed at 512. |
